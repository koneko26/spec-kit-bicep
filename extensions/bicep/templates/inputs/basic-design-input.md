# 入力テンプレート: 基本設計 (/speckit.bicep.basic-design)

通常は引数なしで `spec.md` から自動生成できる。**設計前提を補足したい場合**にだけ、以下を引数で渡す。

## 記入ひな形

```text
優先方針: <例: コスト最優先 / 可用性最優先 / セキュリティ最優先>
リージョン: <主 / 副>
既存資産: <再利用するVNet/サブスク/接続など（Brownfield時）>
特記の制約: <規制、組織標準、既存命名規約など>
未決事項の扱い: <仮置きしてよい / 必ず質問する>
```

## 良い入力例（Few-shot）

```text
優先方針: セキュリティ最優先（次点で可用性）
リージョン: 主=Japan East / 副=Japan West
既存資産: 既存の接続用 ExpressRoute と DNS プライベートゾーンを再利用
特記の制約: 組織のCAF命名規約 v2 に準拠、公開エンドポイント全面禁止
未決事項の扱い: 影響が大きいものだけ質問、それ以外は妥当な既定で仮置き
```
